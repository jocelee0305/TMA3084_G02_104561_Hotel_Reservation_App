## Hotel Reservation App v0.2.0-prototype

Milestone M2: Design and Prototype (Week 9)

### What works

- Booking form with validation for name, phone, check-in date, and hotel policy
- Date picker, guest slider, room type buttons, and breakfast switch
- Room list screen with one expansion panel for each room type
- Snack bar message after a valid booking
- Customized UI: teal theme, welcome banner, styled room cards, banner animation, and page transition

### Quality

- 22 automated tests: validator unit tests and widget tests
- CI runs analyze and tests on every push and pull request
- CI uploads the coverage report as the coverage-report artifact

### Known gaps

- Bookings are not saved yet
- Only two screens exist in this lab app
